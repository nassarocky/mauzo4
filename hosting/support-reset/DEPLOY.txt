Moved to web/support-reset/ — bundled with Flutter web build.

Supports password reset, user/shop edits, and role reassignment
(owner / manager / cashier / sales_person / agent / employee).

Deploy:
  firebase deploy --only functions   # required for adminSupportResolveUser + adminSupportGetRecord / adminSupportUpdateRecord
  flutter build web --release
  firebase deploy --only hosting

URL after deploy:
  https://YOUR_HOSTING_DOMAIN/support-reset/

(Static files are served before the SPA rewrite; main app at / is unchanged.)
