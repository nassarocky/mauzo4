Admin hub — single sign-in for commission admins, then links to businesses browser, support-reset and agent-portal.

URL (after Flutter web build + hosting deploy):
  https://YOUR_HOSTING_DOMAIN/admin-hub/
  https://YOUR_HOSTING_DOMAIN/admin-hub/businesses.html
  https://YOUR_HOSTING_DOMAIN/admin-hub/sms.html

Copy this folder into build/web/admin-hub/ before firebase deploy --only hosting (same as web/support-reset and web/agent-portal).

Requires:
  - commission_admins/{uid}
  - Cloud Functions: commissionAdminPing, adminListBusinesses
  - Firestore indexes for businesses filters (firebase deploy --only firestore:indexes)
